# LocalLang Tanzania AI — Bright White Tailwind UI

## Files
- `index.html` — main page
- `script.js` — 50-language loop, professional slider, dark/white mode, mobile menu and reveal animations
- `image/` — place your real project images here

## Images
The HTML expects the image names used in your previous design, for example:
- `maasai.jpg`
- `general.jpg`
- `social.jpg`
- `recommendation.jpg`
- `doctors.jpg`
- `teachers.jpg`
- `doctors ss.jpg`
- `General communication.jpg`
- `IF WE USE AI.jpg`

If an image is missing, the page uses an online fallback image so the layout still works.

## Tailwind
This version uses Tailwind through the CDN, so there is no Node/npm setup required to preview it.
Open `index.html` in Chrome while connected to the internet.

For a production/offline build, install Tailwind locally and compile the classes into a static CSS file.
